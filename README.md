# Tennis for Two — Oscilloscope XY

Two implementations of the 1958 oscilloscope game, generated by two different AIs and compared side by side.

```
Left audio channel → X axis
Right audio channel → Y axis
Oscilloscope in X-Y mode
```

---

## Versions

### `tennis_for_two_claude.py` — Claude Sonnet 4.6
- Vector frame assembled each tick: court → net → ball → paddles, stitched with blanking ramps
- Phosphor simulation via `numpy` accumulation buffer with per-frame decay (`phosphor *= 0.82`)
- Game loop paced to exactly match audio sample rate (~92 fps)
- Score overlay rendered with `pygame.font`
- Restart resets scores + paddles + ball

### `tennis_for_two_gemini.py` — Gemini
- Fixed 60 fps loop; frame resampled to constant buffer length with `np.interp`
- Beam velocity used to vary line brightness (fast = dim = blanking simulation)
- Alpha-blended black overlay for phosphor persistence instead of a decay buffer
- Gravity physics on the ball (`ball_vy -= 0.0008` per frame)
- Diamond-shaped ball (4-point path)

## Install

```bash
pip install numpy sounddevice pynput pygame
```

Or use the launcher:

```bash
chmod +x tennis.sh
./tennis.sh   # installs deps + runs the Claude version
```

---

## Run

```bash
python3 tennis_for_two_claude.py   # Claude version
python3 tennis_for_two_gemini.py   # Gemini version
```

| Quit | `ESC` | `ESC` |

---

## Oscilloscope setup

1. Connect stereo audio output to oscilloscope
2. Set mode to **X-Y** (or Lissajous)
3. Left channel → X input, right channel → Y input
4. Start at ~1 V/div and adjust until the court fills the screen

The pygame window is a software phosphor simulation — useful without hardware.
